Coding with AI can be a bit sian when it only talks like a textbook. So we made sg-skill.pct, a Claude Code skill that speaks Singlish lah! 🇸🇬

Type "eh the build fail again leh, why like that?" and Claude answers the same way, at your level, from light "can" to full kopitiam. Your code, comments and commits still come out in proper standard English, so nothing weird gets shipped.

Got 212 Singlish words and phrases with meanings and origins, three intensity levels, and zero vulgar slang. Steady!
