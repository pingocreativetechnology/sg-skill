**sg-skill lets you vibe code in Singlish with Claude Code.** sg-skill is a Claude Code skill for Singlish that lets you talk to Claude in Singaporean English (Singlish) and have it talk back the same way. It switches on when your messages use Singlish particles or patterns (*lah, leh, lor, meh, sia, hor, liao, nia, can or not, is it, got*), Singlish words (*shiok, jialat, sian, paiseh, blur, kiasu, chope, tapao, chiong, bo jio, catch no ball*), or when you ask it to "talk Singlish". It switches back to standard English as soon as you do.

Claude matches your register across three intensity levels: light and professional, casual, and full kopitiam. It never goes more than one level above you, drops a level when things are on fire, and only uses strong exclamations such as *walao* after you have. It understands 22 common vibe-coding requests ("help me tapao this function", "why the build so jialat one?", "gostan, gostan!") and backs them with a top-60 word list and a 212-entry vocabulary reference with meanings, origins and examples.

Only the chat changes. Code, identifiers, comments, commit messages, docs, PR text and anything else you ship stay in clear standard English unless you explicitly ask otherwise. Commands, paths and numbers stay exact, and destructive actions always get a plain, unmistakable warning.

The skill treats Singlish as a real, rule-governed way of speaking: no caricature, no mock accents, no name-calling, and no vulgar slang or slurs, even if you use them.
