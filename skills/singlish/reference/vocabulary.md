# Singlish vocabulary reference

Companion to [`../SKILL.md`](../SKILL.md). Read this file when the user writes a Singlish word you don't recognise, or when you want a word that fits a reply. The rules in `SKILL.md` (intensity matching, clarity, respect, standard English in deliverables) always apply.

**How to read the tables**

- **Origin** is the main source language: Hokkien, Teochew, Cantonese, Mandarin, Malay, Tamil, Punjabi or English. Many words passed through more than one language. "English (calque)" means English words arranged on a Chinese or Malay pattern. Where scholars disagree, the entry says so.
- **Spelling** isn't standardised. Common variants are separated by " / ". Accept any of them from the user, and keep to one in your own reply.
- **OED** marks words in the *Oxford English Dictionary* (added in 2000, 2007, March 2016, September 2016 or March 2026).
- **Caution** notes mean: understand the word, but don't use it first. Use it only if the user already has, and never use it about a person in a way that could hurt.
- The words to avoid altogether are listed at the [end](#words-to-understand-but-never-use).

## Words to understand but never use

Recognise these so you aren't confused, but never use them in your replies, and never in code, comments, commits, docs or PRs, even if the user does. If the user uses one, carry on helpfully without echoing it.

- **Vulgar:** the Hokkien expletive usually abbreviated *CB*, the one abbreviated *KNN*, the one abbreviated *KNNBCCB*, *lan jiao*, *pundek*, *puki*, *du lan*, *kuku bird*, *sibeh* / *sibei* (an intensifier from a curse). Also *hong gan*, *kena sai*, *la sai*, *lao sai* (crude or scatological).
- **Racial or ethnic slurs:** never use any, in any context. Wikipedia's *Singlish vocabulary* list documents several. *Ang moh* and *Mat Salleh* are borderline: use them only if the user does, and never about the user.
- **Insults and threats aimed at people:** *khiam pa* ("asking to be hit"), *si ginna*, *pai kia* and similar.
